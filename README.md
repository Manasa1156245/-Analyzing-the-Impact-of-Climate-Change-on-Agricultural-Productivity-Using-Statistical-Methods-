# Analyzing the Impact of Climate Change on Agricultural Productivity Using Statistical Methods

## Project Overview

This project analyzes the impact of climate change on agricultural productivity using statistical methods and data analysis techniques. The study examines climate-related and agricultural factors to understand their relationship with crop productivity.

Python and Jupyter Notebook are used for data preprocessing, exploratory data analysis, data visualization, correlation analysis, and statistical analysis.

## Objectives

- Analyze the relationship between climate change factors and agricultural productivity.
- Clean and preprocess the dataset for analysis.
- Identify patterns and relationships among climate and agricultural variables.
- Perform statistical analysis to study relationships between variables.
- Visualize important trends and relationships in the dataset.
- Interpret the statistical findings using data-driven methods.

## Dataset

The project uses the **Climate Change Impact on Agriculture 2024** dataset.

The dataset contains **10,000 records and 15 attributes** related to climate, agriculture, geography, irrigation, soil health, and adaptation strategies.

## Project Purpose

### Purpose of the Project

The main purpose of this project is to **analyze how selected climate and agricultural factors are associated with crop yield** using statistical methods. It aims to identify important relationships between variables such as **temperature, precipitation, and CO₂ emissions** and agricultural productivity. The project also compares crop yield across **countries, regions, crop types, and adaptation strategies**, examines **changes in yield over time**, and evaluates whether adaptation strategies are associated with differences in productivity. Overall, the project aims to provide **data-driven insights into climate–agriculture relationships** that can support better understanding of agricultural productivity and sustainable agricultural planning.
